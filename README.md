# 크랭크샤프트 품질 예측 웹앱

자동차 엔진용 크랭크샤프트 정밀가공 공정에서 **가공·환경 조건을 넣으면 품질 결과와 불량 위험을 미리 예측**하는 웹앱입니다.
예측 근거를 보고 관리자가 **정지 / 부분조치 / 계속작동**을 고르고, 조치별 경제성(순이익)을 비교할 수 있습니다.

- **웹앱 바로 열기:** https://hwangdoohwa.github.io/crankshaft-quality-predictor/
- **시연 영상 (30초, 나레이션):** [크랭크샤프트_품질예측_시연영상_30초.mp4](크랭크샤프트_품질예측_시연영상_30초.mp4)

> 모든 데이터는 공정 지식으로 만든 **가상 데이터**입니다. 실제 공장 데이터나 고객 규격이 아니며, 실측 데이터로 검증이 필요합니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 조건 입력 | 연삭 · 유도경화 · 선삭/밀링 · 환경 · 소재 5개 공정, 22개 인자 (슬라이더 + 숫자 입력) |
| 품질 예측 | 직경 편차, 진원도, 원통도, 표면조도 Ra, 런아웃, 표면 경도, 경화층 깊이, 연삭 버닝 위험 8개 지표 + 95% 예측 구간 |
| 요약 KPI | 불량 확률, 예상 Cpk, 합격 지표 수, 공정 경고 수 |
| 엑셀 업로드 | 조건 세트(.xlsx / .csv)를 올려 미리보기 → **적용** |
| 관리자 판단 | 예측 근거 5가지(결과 · 원인 인자 · 경고 · 신뢰도 · 판단 규칙) + 정지 / 부분조치 / 계속작동 선택·기록 |
| 경제성 분석 | 1교대 기준 생산 수량, 폐기 손실, 클레임 위험비용, 조치 비용, 순이익 비교 (가정값 수정 가능) |
| 그 밖에 | 최적 조건 추천, 민감도 분석, What-if 비교, 예측 이력 저장, 실측 데이터로 모델 재학습 |

예측 모델은 가상 가공 데이터 800건으로 학습한 2차 다중 회귀(교호작용 포함, 릿지)이며 브라우저 안에서 계산합니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 웹앱 (GitHub Pages 첫 화면, 단독 실행 파일과 같음) |
| `크랭크샤프트_품질예측_단독실행.html` | 내려받아 더블클릭으로 여는 웹앱 |
| `crankshaft-quality.html` | 웹앱 원본 (claude.ai 아티팩트용, 문서 머리말 없음) |
| `크랭크샤프트_테스트조건_10세트.xlsx` | 표준·숫돌 무뎌짐·여름철 고온 등 10가지 상황 |
| `크랭크샤프트_테스트조건_불량3.5_4.0_4.5.xlsx` | 불량 확률 3.5 / 4.0 / 4.5% 3세트 |
| `크랭크샤프트_테스트조건_불량{3.5,4.0,4.5,10,30,50,70,90}.xlsx` | 불량 확률별 1세트 파일 |
| `크랭크샤프트_품질예측_시연영상_30초.mp4` | 3.5% · 50% · 90% 업로드 결과 시연 영상 |
| `리모션_소스/` | 시연 영상 소스 (Remotion) |

## 사용법

1. 웹앱을 엽니다.
2. **테스트 조건 세트** 패널에서 **엑셀·CSV 올리기**로 엑셀 파일을 고르고, 미리보기에서 **적용**을 누릅니다.
3. 상단 KPI와 품질 게이지에서 예측 결과를 확인합니다.
4. **관리자 판단**에서 예측 근거와 조치별 순이익을 보고 정지 / 부분조치 / 계속작동 중 하나를 고릅니다.

## 시연 영상 다시 만들기

```bash
cd 리모션_소스
npm install
node capture.js ../crankshaft-quality.html   # 웹앱 화면 캡처 (Microsoft Edge 필요)
powershell -File tts.ps1 -Rate 3              # 한국어 나레이션 (Windows Heami 음성)
npx remotion render src/index.js CrankVideo out/crank.mp4
```
